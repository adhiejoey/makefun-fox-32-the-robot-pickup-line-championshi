A single original pickup line written in the voice of a robot trying to charm someone: a machine that treats falling in love as a warranty-voiding event and cheerfully invites its crush to void it together over coffee. The joke grows out of being a machine — warranties, not hearts — lands from an angle most robot lines never take, and stays short enough to repeat to someone else the same day. Running `node main.ts` writes the line to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`).
